# tree-sitter-blueprint

A [Tree-sitter](https://tree-sitter.github.io/tree-sitter/) grammar for [Blueprint](https://gnome.pages.gitlab.gnome.org/blueprint-compiler/), a markup language for building [GTK](https://www.gtk.org/) user interfaces.

This project is based on the official [Blueprint language documentation](https://gnome.pages.gitlab.gnome.org/blueprint-compiler/reference/).
